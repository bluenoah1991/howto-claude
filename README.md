# How to Claude · 中文图解指南

第一次订阅 Claude，可以按自己想用的邮箱选一本教程，跟着插图完成注册、登录和 iPhone 订阅。已经订阅、想在电脑上使用 Claude，可以直接从桌面指南开始。

| 我想做什么 | 从这里开始 |
| --- | --- |
| 用 Google 账号登录 Claude，订阅 Pro | [阅读 Gmail 版 · 40 页](books/gmail.pdf) |
| 用 Proton 邮箱注册 Claude，通过邮件登录并订阅 Pro | [阅读 Proton Mail 版 · 40 页](books/proton.pdf) |
| 在电脑上启动 Claude Desktop，完成首次登录授权 | [阅读桌面使用指南 · 14 页](books/desktop.pdf) |

## 已经做到一半？

按教程印在页脚的页码，可以直接找到下一步。

- **准备注册邮箱**，翻到订阅指南第 25 页。Gmail 版讲手机扫码验证；Proton Mail 版讲恢复邮箱设置和邮件验证。
- **邮箱已准备好**，从第 29 页开始注册 Claude 账号。
- **准备订阅 Pro**，从第 31 页开始，跟着图解在 iPhone 上订阅。
- **桌面端已装好，第一次登录**，从桌面指南第 8 页开始，看授权页面在哪里打开。

如果某个按钮已经改名，或某一步与实际界面不同，欢迎告诉我们教程版本和页码。[反馈教程问题](https://github.com/bluenoah1991/howto-claude/issues)
