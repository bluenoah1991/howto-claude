# How to Claude · 中文图解指南

面向中文读者的 Claude 图解操作指南，从网络与浏览器环境准备、邮箱与 Claude 账号注册、在 iPhone 上完成 Pro 订阅，到在电脑上安装并登录 Claude Desktop，一步一步跟着插图即可完成。

## 选择适合你的教程

| 我想做什么 | 从这里开始 |
| --- | --- |
| 用 Google 账号注册登录 Claude，并在 iPhone 上订阅 Pro | [订阅指南 · Gmail 版（40 页）](books/gmail.pdf) |
| 用 Proton 邮箱接收验证邮件、登录 Claude 并订阅 Pro | [订阅指南 · Proton Mail 版（40 页）](books/proton.pdf) |
| 已有 Claude 账号，在电脑上安装并首次登录授权桌面端 | [Claude Desktop 使用指南（14 页）](books/desktop.pdf) |

## 教程内容与进度索引

按教程页脚的页码，可以直接了解每部分讲什么，或跳到中断的步骤继续操作：

### 订阅指南（Gmail 版 / Proton Mail 版）

- **第 1 页 · 准备网络**：配置稳定的代理网络环境
- **第 7 页 · 准备浏览器**：设置独立、干净的浏览器环境
- **第 15 页 · 手机网络**：配置 iPhone 侧的网络环境
- **第 25 页 · 注册邮箱**：Gmail 版讲解手机扫码验证；Proton Mail 版讲解恢复邮箱设置与邮件验证
- **第 29 页 · 注册 Claude**：完成 Claude 账号注册与邮箱登录
- **第 31 页 · 订阅与付款**：在 iPhone 上完成 Apple 账户充值与 Pro 订阅
- **第 39 页 · 结束语**：后续使用建议与收尾说明

### Claude Desktop 使用指南

- **第 1 页 · 系统代理**：检查并设置电脑系统代理
- **第 2 页 · 配置 Baton**：完成中继代理软件的配置
- **第 7 页 · 启动桌面端**：启动 Claude Desktop 客户端
- **第 8 页 · 首次登录**：在桌面端完成账号授权与登录
- **第 13 页 · 结束语**：日常使用注意事项

## 配套工具与常用网站

教程中用到的外部工具与官方入口如下：

- **购买代理 IP**：[Proxy-Cheap](https://www.proxy-cheap.com/)、[IPRoyal](https://iproyal.com/)、[NodeMaven](https://nodemaven.com/)（选购住宅或静态住宅 ISP 代理 IP）
- **常用软件**：[Chrovia PersonaHub](https://console.getchrovia.com/zh/products/persona-hub)（指纹浏览器，隔离不同身份与登录状态）、[Baton](https://baton.getchrovia.com/zh#download) 与 [Baton 浏览器插件](https://chromewebstore.google.com/detail/baton/gcpdpgamadbohahegdkfagajneeibcni)（中继代理与浏览器连接管理）、[忍者蟹（ClawdNinja）](https://github.com/ChroviaHQ/ClawdNinja/releases)（使用指定代理启动 Claude Desktop）
- **环境检测**：[IPinfo](https://ipinfo.io/what-is-my-ip)、[IP2Location](https://www.ip2location.com/demo)、[Scamalytics](https://scamalytics.com/)、[IPQualityScore（IPQS）](https://www.ipqualityscore.com/ip-fraud-score-risk-checker)、[Fingerprint Playground](https://demo.fingerprint.com/playground)（检查出口 IP、地理位置、风险评分与浏览器指纹）
- **邮箱与账号注册**：[Google 账号](https://accounts.google.com/signup)、[Proton Mail](https://proton.me/zh/mail)、[Claude](https://claude.ai/login)、[Apple 账户（Apple ID）](https://account.apple.com/account)
- **礼品卡与付款**：[PockytShop](https://shop.pockyt.io/goodsDetail/9WLYdh2/Apple%20Gift%20Card%20US/all)（购买美区 Apple 礼品卡，为 Apple 账户充值）
